# Campaign Studio — Marketing Website

This folder contains the first public marketing-site build for Campaign Studio.

## Stack
- Static HTML, CSS and a tiny vanilla JavaScript enhancement
- No paid API or AI provider integration in this website phase
- Designed to deploy from this folder as the Vercel Root Directory

## Local preview
Open `index.html` in a browser.

## Current scope
- Responsive product landing page
- Workflow and capabilities sections
- Clearly labelled illustrative skincare campaign preview
- Early-access CTA placeholder

## Next steps
1. Connect a real early-access form and contact destination.
2. Build the separate portfolio website in its own project/root.
3. Build the authenticated SaaS workspace.
4. Design and implement the first-party campaign API later.

No campaign generation, authentication, checkout, or data storage is implemented by this static marketing page yet.
