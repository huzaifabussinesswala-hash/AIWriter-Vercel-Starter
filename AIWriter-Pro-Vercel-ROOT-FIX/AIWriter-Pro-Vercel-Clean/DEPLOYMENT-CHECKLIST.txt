AIWriter Pro - clean Vercel project layout

IMPORTANT: Upload the CONTENTS of this folder to the GitHub repository root.
Do not upload this folder as an extra nested folder.

At the repository root you should see:
  web_app.py
  requirements.txt
  pyproject.toml
  vercel.json
  templates/
  static/
  tests/

Vercel settings:
  Root Directory: ./ (repository root)
  Framework Preset: Other (if Vercel asks)
  Build command: leave default/empty unless Vercel requires otherwise

Environment variables required for production:
  SECRET_KEY = generate with: python -c "import secrets; print(secrets.token_hex(32))"
  DATABASE_URL = hosted PostgreSQL connection string (for example, from Neon)
  AI_API_URL = reachable OpenAI-compatible chat completions endpoint
  AI_API_KEY = provider API key
  AI_MODEL = model identifier accepted by that provider

For email verification, configure MAIL_SERVER, MAIL_PORT, MAIL_USE_TLS,
MAIL_USERNAME, MAIL_PASSWORD, and MAIL_DEFAULT_SENDER.

Never commit .env, actual secrets, database passwords, or API keys.
After changing environment variables, redeploy. Check Build Logs first if a
dependency import fails. Runtime logs alone do not show why a package was not installed.

This folder is statically checked, but a successful Vercel deployment cannot be
guaranteed until the repository and environment variables are configured in Vercel.
