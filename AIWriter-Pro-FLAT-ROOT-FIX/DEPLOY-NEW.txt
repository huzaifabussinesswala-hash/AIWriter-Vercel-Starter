AIWRITER PRO — CLEAN VERCEL DEPLOYMENT

IMPORTANT ROOT STRUCTURE
Upload the CONTENTS of this folder to the GitHub repository root. Do not upload this enclosing folder.
At repository root, you must see app.py, web_app.py, requirements.txt, pyproject.toml, templates/, and static/.
There must NOT be AIWriter-Pro-NEW/AIWriter-Pro-NEW/ or AIWriter-Pro-Vercel-Clean/AIWriter-Pro-Vercel-Clean/ nesting.

VERCEL
1. Create a NEW GitHub repository and upload the contents of this folder to its root.
2. Create a NEW Vercel project imported from that repository (do not reuse the old project for the first test).
3. Root Directory: leave blank/default (repository root).
4. Framework preset: Other or let Vercel auto-detect. Do not set a custom build command or output directory.
5. Add environment variables before deployment:
   SECRET_KEY = a long random secret (generate with: python -c "import secrets; print(secrets.token_hex(32))")
   DATABASE_URL = a hosted PostgreSQL connection string (for example from Neon; SQLite is not persistent/recommended on Vercel)
   AI_API_URL = your AI provider's compatible generation endpoint
   AI_API_KEY = your provider API key
   AI_MODEL = your provider's model name
6. If email verification is enabled, configure MAIL_SERVER, MAIL_PORT, MAIL_USERNAME, MAIL_PASSWORD, and MAIL_DEFAULT_SENDER.
7. Deploy. Then open /health to check database connectivity.

LIMITS
This archive fixes the project root/entrypoint layout, but it cannot guarantee a successful deployment without valid environment variables and a reachable PostgreSQL database. Never share SECRET_KEY, database credentials, or AI_API_KEY publicly.
